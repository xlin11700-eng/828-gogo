# 地块账本 · 开发投资测算

比较新旧销售条件下的项目收益、税负和资金占用，支持售价与分期开发假设。此目录为已构建的静态网站，可直接发布至 GitHub Pages。

## 发布

1. 在自己的 GitHub 账号下创建公开仓库，例如 land-cashflow-828。
2. 将此目录中的 index.html、assets 文件夹和 .nojekyll 文件上传到仓库根目录。先解压再上传文件，不要只上传 ZIP。
3. 仓库 Settings → Pages → Build and deployment → Source 选择 Deploy from a branch。
4. 选择 main 分支及 / (root)，保存。等待 Pages 部署成功后，使用该页面显示的网站链接。
5. 在大陆手机网络及微信内打开网站，验证页面和测算交互后再对外分享二维码。

## 测算口径

本工具用于基于输入假设的项目方案比较。税费采用一般计税的商品住宅项目通用估算口径，实际项目应确认地方政策、纳税主体与清算单位。分期模型假定各期独立测算相关税费，未替代企业层面的纳税申报与跨期清算。

此发布包中的主程序和样式已本地打包，基础测算不需要独立后端服务器。公开静态网页中的程序代码可以被访问者查看。
